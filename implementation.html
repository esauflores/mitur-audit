phase 1 · PR 1 local · 5 min

Cache HTML at Cloudflare's edge. 7 of 8 pages are cacheable.

mechanism

WordPress returns cache-control: no-store on every response. Cloudflare respects this and serves HTML as DYNAMIC for every pageview. Static assets are 89% cached; HTML is 0%.

the fix (Cloudflare dashboard)
Rules → Page Rules → Create
URL: mitur.gob.sv/*
Cache Level: Cache Everything
Edge Cache TTL: 1 hour
Browser Cache TTL: 5 min

+ second rule to bypass cache for wp-admin / wp-login
Verify: curl -sI https://www.mitur.gob.sv/ | grep cf-cache-status should show HIT on the second request. Expected outcome: HTML edge-cache hit rate 0% → 95%+. Origin render count drops by ~95%.
phase 1 · PR 2 local · 5 min

Dequeue the second jQuery. Theme ships 3.3.1, WP core has 3.7.1.

mechanism

The theme bundles jquery-3.3.1.js (269 KB). WP core ships jquery.min.js (3.7.1, 30 KB). Both load sync in <head> and both parse + exec. ~820 ms of redundant CPU per pageview.

the fix
// wp-content/themes/instituciones-child/functions.php
add_action('wp_enqueue_scripts', function () {
    wp_dequeue_script('instituciones-jquery-3.3.1');
    // (handle name may vary; check the theme's wp_enqueue_script call)
}, 20);  // priority 20 = runs AFTER theme's enqueue
Verify: curl -s https://www.mitur.gob.sv/ | grep -oE 'jquery[^"]*\.js' | sort -u should return one line (WP core only). Expected outcome: 820 ms CPU win on every pageview.
phase 1 · PR 3 + PR 8 local · 3 days

Defer 51 sync scripts. Page-gate per plugin.

PR 3 · defer scripts (in functions.php)
add_filter('script_loader_tag', function ($tag, $h) {
  if (in_array($h, ['jquery', 'jquery-core'])) return $tag;
  if (strpos($tag, ' defer') !== false) return $tag;
  return str_replace(' src=', ' defer src=', $tag);
}, 10, 2);
PR 8 · page-gate per plugin (functions.php)
add_action('wp_enqueue_scripts', function () {
  if (!is_page('contacto'))
    wp_dequeue_script('contact-form-7');
  if (!is_singular('photo_contest'))
    wp_dequeue_script('smartslider3');
  if (!is_admin()) wp_dequeue_script('plupload');
  // ... 5 more plugins per page-type
}, 100);

Or install Perfmatters (recommended) — declarative per-page UI, no PHP required.

Verify: curl -s https://www.mitur.gob.sv/ | grep -oE '<script[^>]*src=[^>]+></script>' | wc -l should drop from 51 to ~5-10. Expected outcome: TBT 300 ms → 150-200 ms; HTML size 225 KB → 120 KB.
phase 1 · PR 4 + PR 5 local · 15 min PR 5: build step · 1 day

336 KB of admin CSS on public pages. Stop shipping it.

PR 4 · block-editor CSS (5 lines of PHP)
add_action('wp_enqueue_scripts', function () {
  if (is_admin()) return;
  wp_dequeue_style('wp-block-library');
  wp_dequeue_style('wp-block-library-theme');
  wp_dequeue_style('wp-block-editor');
  wp_dequeue_style('wp-components');
}, 100);
PR 5 · PurgeCSS (build step)
# package.json script
"build:css": "purgecss --css theme/style.css
  --content 'theme/**/*.php' --output dist/style.purged.css
  --safelist theme-no-delete"

# enqueue the purged version
wp_enqueue_style('instituciones',
  get_template_directory_uri() . '/../dist/style.purged.css');
Verify: curl -s https://www.mitur.gob.sv/ | grep -E 'block-library|block-editor|components' should return nothing. Expected outcome: 336 KB of admin CSS removed; 1.15 MB of unused CSS removed by PurgeCSS.
