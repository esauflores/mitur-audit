fase 1 · PR 1 local · 5 min

Caché HTML en el edge de Cloudflare. 7 de 8 páginas son cacheables.

mecanismo

WordPress devuelve cache-control: no-store en cada respuesta. Cloudflare respeta esto y sirve el HTML como DYNAMIC para cada visita. Los assets estáticos se cachean al 89%; el HTML al 0%.

el fix (dashboard de Cloudflare)
Rules → Page Rules → Create
URL: mitur.gob.sv/*
Cache Level: Cache Everything
Edge Cache TTL: 1 hour
Browser Cache TTL: 5 min

+ segunda regla para bypass de caché en wp-admin / wp-login
Verificar: curl -sI https://www.mitur.gob.sv/ | grep cf-cache-status debe mostrar HIT en la segunda petición. Resultado esperado: tasa de acierto de caché HTML 0% → 95%+. Las renderizaciones en el origen caen ~95%.
fase 1 · PR 2 local · 5 min

Quita el segundo jQuery. El tema trae 3.3.1, el core WP tiene 3.7.1.

mecanismo

El tema agrupa jquery-3.3.1.js (269 KB). El core de WP trae jquery.min.js (3.7.1, 30 KB). Ambos cargan sincrónicamente y ambos parsean + ejecutan. ~820 ms de CPU redundante por visita.

el fix
// wp-content/themes/instituciones-child/functions.php
add_action('wp_enqueue_scripts', function () {
    wp_dequeue_script('instituciones-jquery-3.3.1');
    // (el handle puede variar; revisa el wp_enqueue_script del tema)
}, 20);  // prioridad 20 = corre DESPUÉS del enqueue del tema
Verificar: curl -s https://www.mitur.gob.sv/ | grep -oE 'jquery[^"]*\.js' | sort -u debe devolver una línea (solo el core WP). Resultado esperado: 820 ms de CPU recuperado en cada visita.
fase 1 · PR 3 + PR 8 local · 3 días

Diferir 51 scripts sync. Page-gating por plugin.

PR 3 · diferir scripts (en functions.php)
add_filter('script_loader_tag', function ($tag, $h) {
  if (in_array($h, ['jquery', 'jquery-core'])) return $tag;
  if (strpos($tag, ' defer') !== false) return $tag;
  return str_replace(' src=', ' defer src=', $tag);
}, 10, 2);
PR 8 · page-gating por plugin (functions.php)
add_action('wp_enqueue_scripts', function () {
  if (!is_page('contacto'))
    wp_dequeue_script('contact-form-7');
  if (!is_singular('photo_contest'))
    wp_dequeue_script('smartslider3');
  if (!is_admin()) wp_dequeue_script('plupload');
  // ... 5 plugins más por tipo de página
}, 100);

O instala Perfmatters (recomendado) — UI declarativa por página, sin PHP requerido.

Verificar: curl -s https://www.mitur.gob.sv/ | grep -oE '<script[^>]*src=[^>]+></script>' | wc -l debe caer de 51 a ~5-10. Resultado esperado: TBT 300 ms → 150-200 ms; tamaño HTML 225 KB → 120 KB.

PR 4 · block-editor CSS (5 líneas de PHP)
add_action('wp_enqueue_scripts', function () {
  if (is_admin()) return;
  wp_dequeue_style('wp-block-library');
  wp_dequeue_style('wp-block-library-theme');
  wp_dequeue_style('wp-block-editor');
  wp_dequeue_style('wp-components');
}, 100);
PR 5 · PurgeCSS (paso de build)
# script de package.json
"build:css": "purgecss --css theme/style.css
  --content 'theme/**/*.php' --output dist/style.purged.css
  --safelist theme-no-delete"

# encola la versión purgada
wp_enqueue_style('instituciones',
  get_template_directory_uri() . '/../dist/style.purged.css');
Verificar: curl -s https://www.mitur.gob.sv/ | grep -E 'block-library|block-editor|components' no debe devolver nada. Resultado esperado: 336 KB de CSS admin eliminados; 1.15 MB de CSS sin usar eliminado por PurgeCSS.
